# BrenOS 1.0 — Premium Windows 11 Branding

BrenOS Nexus is an original orbital emblem (not a letter B). The archive includes original vector wallpaper and icon sources, 50 Windows ICO icons, PNG previews, 4K, QHD, FHD and ultrawide wallpaper variants, 15 cursor resources and 5 sound effects.

**Install:** Download `BrenOS-1.0-Windows11.zip`, extract it, run `PREVIEW.cmd` and then `INSTALL.cmd`.

**Restore:** `RESTORE.cmd` returns saved visual preferences. `RESTORE-CLEANUP.cmd` returns optional cleanup values.

**Safe Cleanup:** `SAFE-CLEANUP.cmd` is optional and asks for confirmation. No Windows components or applications are removed. Microsoft Defender, Windows Update, UAC, SmartScreen, boot and secure desktop stay unchanged.

**AtlasOS:** Not included or automatically installed. See `docs/ATLASOS.md`.

**Verification:** GitHub Actions validates assets and Windows PowerShell syntax. Runtime behavior on Windows 11 devices, multi-monitor arrangements and high-DPI windows still needs separate device testing.
