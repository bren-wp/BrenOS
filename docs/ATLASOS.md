# AtlasOS kao zasebna mogućnost

BrenOS radi na postojećem, legalno instaliranom Windowsu 11 i **ne zahtijeva AtlasOS**.

AtlasOS je zaseban GPLv3 projekt koji se instalira playbookom kroz AME Wizard, a nije drugi kernel ili vlastiti Windows ISO. BrenOS ne preuzima njegov kod i ne izvršava tuđe playbookove.

Prema službenoj dokumentaciji (provjereno 29.10.2026.), svježa instalacija Atlasa traži ponovno instaliranje Windowsa, kao i eventualno uklanjanje Atlasa. Atlas trenutačno podržava odabrane stabilne verzije Windows 11 (25H2), ne Windows Home.

- [Službeni AtlasOS repozitorij](https://github.com/Atlas-OS/Atlas)
- [Službena instalacija](https://docs.atlasos.net/getting-started/install/install-playbook/)
- [Podržani Windows buildovi](https://docs.atlasos.net/faq/install-faq/windows-version-support/)

Ako želiš Atlas, napravi provjerenu vanjsku sigurnosnu kopiju, slijedi službene upute i **tek zatim** instaliraj BrenOS. `RESTORE.cmd` uklanja samo BrenOS personalizaciju, **ne vraća AtlasOS promjene**.
